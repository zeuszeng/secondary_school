## 10–15 分钟首次诊断

诊断用于决定从哪里开始，不用于排名，也不设置强制倒计时。可以中途停止；结束后只展示“已可直接学习、建议先补给、建议优先复习”三类能力分布，并允许 Mya 手动选择路线。

每题都有完整数据、确定答案和有限作答控件；建议总时长 14 分钟，但时间只作节奏参考，不在界面倒数。

| 诊断 ID 与题面 | 控件与提交内容 | 标准答案 | 建议时间 |
|---|---|---|---:|
| `FUNC-DG-01`：表 A 的输入集合 `{1,2,3}`，对应为 `1→4,2→4,3→5`；表 B 的四行是 `(1,3),(2,4),(2,5),(3,6)`，输入集合 `{1,2,3}`。分别判断是否为函数；若否，指出失败输入。 | 两个“是/否”单选；第二题从 `1,2,3,无` 中单选失败输入。 | A 是函数；B 不是函数，失败输入 2。 | 2 分钟 |
| `FUNC-DG-02`：求 `f(x)=sqrt(x+2)/(x-1)` 的定义域。 | 根式条件、分母条件分步选择；区间端点和开闭控件。 | `x≥-2`、`x≠1`；定义域 `[-2,1)∪(1,+∞)`。 | 3 分钟 |
| `FUNC-DG-03`：函数表为 `x:-1,0,2`，`f(x):3,1,5`。求 `f(2)` 并写输出集合。 | 一个数值框；从 `{1,3,5}`、`{-1,0,2}`、`{3,5}` 中单选。 | `f(2)=5`；输出集合 `{1,3,5}`。 | 2 分钟 |
| `FUNC-DG-04`：`f(x)=x^2-1`、`g(x)=(x-1)(x+1)`，定义域都为 R。判断是否为同一函数。 | “相同/不相同”单选；依据卡选择“定义域相同且对应关系恒等”。 | 相同；两者定义域同为 R，展开后规则相同。 | 2 分钟 |
| `FUNC-DG-05`：定义域 `[-3,4]` 上的连续折线依次连接 `(-3,1),(-1,4),(2,-2),(4,3)`。写全部递增、递减区间，并写最大值、最小值及取得位置。 | 三个区间端点控件，多个递增区间用“和”分列；四个数值框填写两个最值及 x。 | 递增区间 `[-3,-1]` 和 `[2,4]`；递减区间 `[-1,2]`；最大值 4 在 x=-1，最小值 -2 在 x=2。 | 3 分钟 |
| `FUNC-DG-06`：`f(x)=x^2` 的定义域为 `[-2,3]`。判断奇偶性，并选择首要依据。 | “奇/偶/非奇非偶”单选；依据卡单选。 | 非奇非偶；首要依据是定义域不关于原点对称。 | 2 分钟 |

确定性路由规则如下：

- `FUNC-DG-01` 任一空错误：从 `M1-C03-S01-K01` 开始。
- `FUNC-DG-02` 错误：若根式或分母条件本身选错，先做定义域补给，再进 `M1-C03-S01-K02`；仅区间开闭错误则直接进 `M1-C03-S01-K02`。
- `FUNC-DG-03` 任一空错误：进 `M1-C03-S01-K03`。
- `FUNC-DG-04` 错误：进 `M1-C03-S01-K04`。
- `FUNC-DG-05` 的单调区间错误：进 `M1-C03-S02-K02`；最值或取得位置错误：进 `M1-C03-S02-K03`；两类都错时依此顺序学习。
- `FUNC-DG-06` 错误：进 `M1-C03-S02-K04`。
- 六题全对：建议从 `M1-C03-S01-K05` 的主路径开始，再完成尚未诊断的 `M1-C03-S01-K06` 与 `M1-C03-S02-K01`；Mya 仍可手动改选任一入口。

诊断记录诊断 ID、正确性、是否使用提示和 Mya 确认的可能错因；它不直接授予“初步掌握”或“稳定掌握”。若某项卡住，先打开相应 3–5 分钟补给，再回到永久节点，不因此锁住其他内容。

## 前置补给

- 集合与区间（3–5 分钟，按需出现，不锁定）：复习 `x∈A`、交集、区间端点开闭。优先连接 `M1-C01-S01-K03` 与 `M1-C01-S03-K03`。
- 不等式与符号（3–5 分钟，按需出现，不锁定）：复习移项、乘除负数变号、乘积符号和简单二次不等式。优先连接 `M1-C02-S01-K03`、`M1-C02-S01-K04` 与 `M1-C02-S03-K03`。
- 坐标与代入（3–4 分钟，按需出现，不锁定）：复习横纵轴、描点、运算顺序、二次函数顶点。

补给只解决当前节点必需的一项基础，不扩展成完整初中复习课。同类错误重复出现时，再推荐专项练习。

## 三种学习入口

- **同步学习**：Mya 选择“老师教到哪里”，按 3.1 → 3.2 → 3.3 → 3.4 开放本周内容。建议每次 2–3 个短节点，总时长不超过 20 分钟。
- **系统自学**：按永久节点的直接前置顺序学习；可预览后续节点，发现缺失前置时自主打开补给。
- **考前冲刺**：先做最近错题对应的基础动作，再处理“核心高频”节点，最后选一道巩固；挑战题不挤占基础复习时间。

每条路线都遵循“本周明显错误 → 当前课程核心 → 必要前置补给 → 少量下周预习”。已掌握节点可直接进入四道基础练习，但提示下完成不计作独立基础通过。

## 作答与掌握度口径

节点状态只有“未学习、学习中、初步掌握、稳定掌握、需要复习”。一次完整基础轮次中，`B01`–`B04` 均无提示独立答对并完成 `M01`，才记为初步掌握；至少间隔 7 天，用四道分别同目标的等价变式再次无提示独立答对，才记为稳定掌握。每次记录题目 ID、正确性、最高已用提示级别、是否独立完成与日期。

巩固与挑战另行记录。挑战失败、未完成或提示下完成不降低基础掌握度，挑战完成也不能替代基础轮次。系统给错因时一律写“可能是……，请确认是否如此”，由 Mya 选择；不显示排行榜、同龄比较或速度名次。
