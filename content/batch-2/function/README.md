## 前置补给

- 集合与区间（3–5 分钟，按需出现，不锁定）：复习 `x∈A`、交集、区间端点开闭。优先连接 `M1-C01-S01-K03` 与 `M1-C01-S03-K03`。
- 不等式与符号（3–5 分钟，按需出现，不锁定）：复习移项、乘除负数变号、乘积符号和简单二次不等式。优先连接 `M1-C02-S01-K03`、`M1-C02-S01-K04` 与 `M1-C02-S03-K03`。

补给只解决当前节点必需的一项基础，不扩展成完整初中复习课。同类错误重复出现时，再推荐专项练习。

## 单元结束挑战

### FUNC-UNIT-X01｜挑战｜函数单元综合｜覆盖：M1-C03-S01-K02、M1-C03-S01-K06、M1-C03-S02-K02、M1-C03-S03-K02、M1-C03-S04-K01、M1-C03-S04-K02

- 变量与边界：输入 x 为正方形展板边长，单位 m；输出面积 `S=x^2`，单位 `m^2`，总制作费 C，单位元；`1≤x≤4`，均按连续量建模；场地只允许这一边长范围，预算为 350 元。
- 题面与作答：面积不超过 4 `m^2` 时每平方米 50 元；超过 4 `m^2` 时前 4 `m^2` 收 200 元，超出部分每平方米 30 元。①从“表格／单个一次式／分段解析式”中选最有效表示；②以 x=2 为界拼出 C(x)，并标每段端点；③判断 C 在 `[1,4]` 上的变化方向；④求预算内可行边长集合与最大边长，答案须带单位。结构化控件只接受表示卡、两段式、端点开闭、单调方向、区间和数值单位卡，不接收自由文本。
- 方向提示：先由面积阈值 4 找边长分界，再分别写两段费用。
- 关键步骤提示：`1≤x≤2` 时 `C=50x^2`；`2<x≤4` 时 `C=200+30(x^2-4)`。两段都随 x 增大而增大，预算只需在各段分别解不等式并取并集。
- 完整解析：最有效表示是分段解析式。`C(x)=50x^2（1≤x≤2）`，`C(x)=30x^2+80（2<x≤4）`；x=2 只归第一段且两侧费用都衔接为 200 元。因 `x^2` 在正区间递增且两段费率为正，C 在 `[1,4]` 上递增。第一段最高费用 200 元，全部满足预算；第二段由 `30x^2+80≤350` 得 `x^2≤9`，结合 x>2 得 `2<x≤3`。合并并与场地范围相交，预算内边长为 `x∈[1,3]` m，最大边长 3 m。
- 标准答案与反馈：选择“分段解析式”；两段及端点、递增方向、可行集合 `[1,3]` m、最大值 3 m 如上。可接受答案把第二段写成 `200+30(x^2-4)`；其余字段只接受题面给定控件中的等价值。若把 x=2 同时放入两段，可能没有保证输入只选一个规则；若最大边长写 `sqrt(9)` 但无单位，可判数值等价但提示补单位；若答到 4 m，可能没有把预算解与现实域取交集。提交前检查：逐项核对“定义域—分段点—单调区间—预算不等式—单位”。

挑战记录与基础掌握分开：首次打开即写 `挑战状态=正在挑战`；只有全部字段完成且答案在可接受集合内才改为 `挑战状态=完成`。答错、未完成或在提示下完成都保持“正在挑战”，不降低任何节点的“初步掌握”或“稳定掌握”，也不替代基础练习。

## 单元掌握出口与复习回路

- 节点初步掌握：该节点一次完整基础轮次中 `B01`–`B04` 全部无提示独立答对，并完成 `M01` 及其复查动作。
- 单元基础出口：15 个永久节点均达到“初步掌握”；只完成单元挑战不能跳过任何节点出口。
- 单元稳定出口：15 个节点分别自初步掌握日起至少间隔 7 天，以四道同目标等价变式全部无提示独立答对；复习记录沿用原题 `source_question_id`，不新发永久题号。
- 需要复习：Mya 手动标记，或基础轮次/间隔复习出现未独立通过的题。保留既有历史证据，只把触发题及其节点送回复习队列。
- 复习回路：从触发题定位永久节点 → 若错误涉及定义域、符号、运算或单位，先开该节点标注的 3–5 分钟按需补给 → 重走该节点必修主路径中的概念归纳与 `EX01` → 重做原 `B` 题并记录提示级别 → 下一次学习用同目标等价变式检查。连续出现跨节点错误时，按上表选择一条最多 20 分钟的短路线。
- 退出复习：原触发题或同目标变式无提示独立通过后，可回到“初步掌握”；“稳定掌握”仍须满足至少 7 天后的四题独立全对，不因一次纠错提前授予。

## 作答与掌握度口径

节点状态只有“未学习、学习中、初步掌握、稳定掌握、需要复习”。一次完整基础轮次中，`B01`–`B04` 均无提示独立答对并完成 `M01`，才记为初步掌握；至少间隔 7 天，用四道分别同目标的等价变式再次无提示独立答对，才记为稳定掌握。每次记录题目 ID、正确性、最高已用提示级别、是否独立完成与日期。

巩固与挑战另行记录。挑战失败、未完成或提示下完成不降低基础掌握度，挑战完成也不能替代基础轮次。系统给错因时一律写“可能是……，请确认是否如此”，由 Mya 选择；不显示排行榜、同龄比较或速度名次。
