## 请确认的四项

1. **课程节奏与语气：** 5–8 分钟节点、20 分钟内路线和面向 Mya 的表达是否合适。
2. **题目质量与难度：** 自编题的条件、解析、提示、易错辨析和难度递进是否可信、清晰。
3. **视频选择与外链方式：** 候选的知识点、状态、版权边界、原页跳转和失效回退是否可接受。
4. **A4 打印效果：** 黑白层级、演算空间、提示与答案隔页，以及实际打印可读性是否合适。
