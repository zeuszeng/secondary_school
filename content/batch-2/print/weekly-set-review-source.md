## 学习卡（第一页）

- **本周核心结论**：集合里的对象必须能够被确定；元素对集合用 `∈/∉`，集合对集合才用 `⊆`；描述法要写清对象、范围、条件。
- **易错提醒**：先圈出左边对象。`a∈A` 表示元素 a 属于集合 A；`{a}⊆A` 才是在说一个集合被包含。`a` 和 `{a}` 不是同一个对象。
- **建议**：先完成四题，再翻页；卡住时只看一级提示。

## 练习（第一页）

### 1. 集合的确定性

判断“高一（3）班身高超过 170 cm 的同学”能否组成一个集合。写出判断，并说明你检查的依据。

### 2. 看整体，填关系符号

已知 `A={-1,0,{0},2}`，在下列横线上填 `∈` 或 `∉`：

`0 __ A`；`{0} __ A`；`1 __ A`；`2 __ A`。

写一句说明：为什么看到 `{0}` 不能直接断定 0 的关系？

### 3. 元素还是集合？

已知 `B={{1,2},3}`。填空：`{1,2} __ B`，`1 __ B`。

小岚写“`1⊆B`”。请改正，并用“左边是____，右边是____”解释原因。

### 4. 两种表示法

（1）把 `C={x∈Z|-2≤x<3}` 改写成列举法。

（2）把 `D={2,4,6,8}` 改写成描述法。答案须包含代表元素、整数范围和条件。

## 分级提示（第二页）

### 1. 集合的确定性

- **一级提示**：看每位同学能否按同一个数值标准被判断。
- **二级提示**：“超过 170 cm”表示身高大于 170 cm，标准明确。
- **答案**：能组成集合；集合成员能被唯一确定。

### 2. 看整体，填关系符号

- **一级提示**：把 A 中逗号分开的每个整体框起来。
- **二级提示**：A 的元素依次是 `-1`、`0`、`{0}`、`2`。
- **答案**：依次为 `∈，∈，∉，∈`。因为 A 同时列出了 0 与 `{0}`；不能把花括号里的对象拆开或凭另一项推断。

### 3. 元素还是集合？

- **一级提示**：`{1,2}` 要作为一个整体与 B 的元素比较。
- **二级提示**：B 的两个元素是集合 `{1,2}` 和数字 3。
- **答案**：`{1,2}∈B，1∉B`；应改为 `1∉B`。1 是元素，B 是集合，不能写 `1⊆B`；`⊆` 两边都应是集合。

### 4. 两种表示法

- **一级提示**：第（1）问从 -2 起逐个列整数，3 不取；第（2）问先找共同特征。
- **二级提示**：D 是 2 到 8 的偶整数；别漏掉 `x∈Z`。
- **答案**：`C={-2,-1,0,1,2}`；`D={x∈Z|2≤x≤8 且 2|x}`。同义的、范围与偶数条件完整的描述法也正确。
