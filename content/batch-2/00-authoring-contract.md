# 第二批课程写作与题目契约

> 适用范围：Mya 的广东惠州高一第一学期、人教 A 版必修第一册课程稿。本文件是集合课程与函数课程的共同写作接口；它落实第一批的永久节点、题目蓝图、难度比例与错因规则，不替代它们。

## 1. 不可变的来源规则

- 节点永久 ID 必须沿用 `M1-Cxx-Sxx-Kxx`；不得重命名、复用或用课程小节标题替代 ID。节点标题、学习目标、重要度、前置补给、建议时长和题目蓝图以第一批覆盖矩阵为准。
- 每道自编题都从所在行的“基础例题主题”三要素展开：考查目标、情境或数据约束、预期方法。题目格写出的变化方向、附加条件或末尾动作只可覆盖或收紧相应要素，不得悄悄删除定义域、符号、区间、整数性或其他已声明条件。
- 题面、解析、图示与互动均为本项目自编；不得复制教材、教辅、真题或第三方页面的题面、图片或解析。不得引入选择性必修内容。
- 一个节点是一个约 5–8 分钟的学习停靠点。前置补给为可选的 3–5 分钟支持，不锁定当前节点，也不计入节点时长。
- 基础支撑节点若矩阵写明“不单设”巩固或挑战，课程稿必须写出矩阵指定的复现位置；不得留空或临时补题。

## 2. 节点正文的固定顺序

每个节点以 `## M1-Cxx-Sxx-Kxx｜节点标题` 开始，并严格按下列二级标题顺序写作。标题后的内容必须是可直接录入课程页的成稿，而不是写作提醒。

1. `### 节点元数据`：永久 ID、学习目标、重要度、前置节点或补给、建议时长、开放条件；补给须标明“按需出现，不锁定”。
2. `### 情境问题`：一句到一小段自编、与本节点数学目标直接相关的问题；交代已知量、单位或范围，避免无关剧情。
3. `### 尝试作答`：给出 Mya 在看讲解前可以完成的明确动作、作答方式和即时可见的核对点；不以倒计时、排名或积分催促。
4. `### 可视化探索说明`：只能二选一：写明“本节点不设置互动”；或完整写出认知目标、初始状态、可操作对象、操作后即时反馈和由观察到概念的提问。互动须服务该节点的定义、图象、对应关系或猜想验证，不能虚构游戏。
5. `### 概念归纳`：用本节点可检验的定义、符号、条件、结论和边界组成简明归纳；需要时给出反例或端点说明，不把口诀代替条件。
6. `### 基础例题`：唯一的 `EX01`，按“审题线索 → 尝试入口 → 分步推理 → 方法总结 → 易错点 → 变式”依次讲解。第二种解法只在它揭示重要联系时加入。
7. `### 基础练习`：恰好四题 `B01` 至 `B04`，题面顺序与矩阵的变体顺序一致；矩阵变体不足四个时按矩阵规则循环或递进展开，而非另造目标。
8. `### 原子化易错辨析`：唯一的 `M01`。题面只嵌入矩阵中“计数错因”所述的一个错误；“诊断候选（不计数）”只在答后反馈中出现，绝不变成第二道题或混入题面。
9. `### 巩固与挑战`：只列矩阵要求的本地巩固、共享池引用或挑战；每题标明难度与所连接的永久节点。共享题只在其归属节点写完整题面、提示、答案和解析，覆盖节点只写题号及归属节点引用。
10. `### 三级提示`：为本节点每一个题号分别提供三个层级的提示，顺序固定为“方向提示 → 关键步骤提示 → 完整解析”。
11. `### 答案与节点总结`：按题号给出答案、可接受答案、关键步骤、错因反馈和提交前检查；随后用“本节点总结”写出一个可复用结论、一个高风险提醒与下一步建议。

课程稿不能以“略”“同理可得”“见上题”“待补”替代任一题的题面、提示、答案、关键步骤或错因说明。题面、提示和答案允许在同一节点内按题号集中编排，但每个题号必须能唯一找到三者。

## 3. 稳定题目编号与归属

`<NODE>` 一律是节点永久 ID。例如 `M1-C01-S01-K01-B01` 的所属节点是 `M1-C01-S01-K01`。题目 ID 全课程全局唯一；同一题不因出现在路线、打印页或复习页而取得新题目 ID。

| 题目类别 | 本地题 ID | 数量与用途 |
|---|---|---|
| 基础例题 | `<NODE>-EX01` | 每节点恰 1 道；用于完整示范。 |
| 基础练习 | `<NODE>-B01` 至 `<NODE>-B04` | 每节点恰 4 道；各自考查一个可独立验证的基础动作。 |
| 易错辨析 | `<NODE>-M01` | 每节点恰 1 道；只诊断一个计数错因。 |
| 本地巩固 | `<NODE>-R01`、`<NODE>-R02` | 只在矩阵要求巩固时使用；用常见变式或少量明确前置稳定方法。 |
| 节点挑战 | `<NODE>-X01` | 只在矩阵要求挑战时使用；必须保留矩阵写明的跨节点连接。 |

本批**不发放**形如 `<NODE>-C01` 的本地题号。计划草案中的 `C` 同时指“巩固或挑战”会造成难度歧义；这里以 `R`（reinforcement，巩固）和 `X`（challenge，挑战）消除歧义，不改变任何永久节点 ID。

共享综合题保持第一批既有的 `SP-Cxx-yy`，例如 `SP-C01-01`；它的 ID、难度“巩固（综合）”和唯一归属节点以共享题池为准。共享题替代归属节点两道巩固中的一道：

- 有共享题的归属节点写一题本地巩固 `R01`，再引用该 `SP` 题；共享题只在归属节点计数一次。
- 覆盖节点可在“巩固与挑战”写“引用 `SP-Cxx-yy`，归属节点为 `…`”，但不复制完整题面，也不计作该节点新增巩固题。
- 无共享题但矩阵要求两道巩固的节点写 `R01`、`R02`；只有一个变化方向时，依矩阵分别覆盖一般情形与已明确的边界情形。
- 共享题不是挑战题；`SP` 题不使用 `R` 或 `X` 的别名。挑战题只用 `X01`，其失败不参与基础掌握度计算。

题目编号只标识题目，不标识一次作答。重做、纸质回收和间隔复习记录使用“作答记录 ID + `source_question_id`”，例如作答记录可引用 `M1-C01-S01-K01-B02`；不得为同一道题另编 `B05`，也不得把一次作答记录当作新题。

## 4. 每题的成题、答案与反馈记录

除共享题在非归属节点的纯引用外，每个题号必须拥有以下完整记录。记录可以按题后写或在节点末尾按题号汇总，但字段含义不得省略。

| 字段 | 必须写清的内容 |
|---|---|
| 题目 ID 与标签 | 完整 ID、所属节点、难度（基础／巩固／挑战／巩固〈综合〉）和对应的矩阵考查目标。 |
| 题面与作答方式 | 完整已知条件、变量范围、单位、图示读法及需要提交的内容；选择、填空、数值输入或分步选择/拖拽之一。关键推理用可检查的分步选择或拖拽，不承诺自动判读任意证明或手写照片。 |
| 标准答案 | 一个唯一规范答案；若数学上允许等价表达，列出完整、有限且可判定的可接受答案集合，并说明规范化规则。不能由答案反推未写进题面的限制。 |
| 关键步骤 | 从已知到答案的必要步骤及每步依据；例题额外遵守“审题线索、尝试入口、分步推理、方法总结、易错点、变式”顺序。 |
| 三级提示 | 同一题固定给出方向提示、关键步骤提示、完整解析；前一级只给下一步方向，后一级可以揭示更多，但不改题目条件。 |
| 原子错因 | `M01` 填矩阵的唯一计数错因；其他题列与本题答案判定直接相关的一个或多个可观察错因，每条都能由某一步或某个选项解释。系统只能显示“可能错因”，由 Mya 确认。 |
| 提交前检查 | 仅在矩阵规定或符号、集合端点、运算顺序、分式/根式、不等号方向、定义域等高风险题中显示矩阵指定动作；写为可执行动作，而非泛泛的“仔细检查”。 |

选择题另有以下硬性规则：每个选项都有唯一的可判定角色；正确项与“标准答案”一致；每个干扰项都要记录其对应的具体错误或漏查条件，例如端点开闭、负数乘除后不等号方向、`∈` 与 `⊆` 混淆。不得以双关、故意遗漏单位、题干歧义或刁钻措辞制造难度。多选题必须明确“全部选出”或“只选一项”，并为所有正确组合给出判定规则。

### 三级提示的强度边界

- **方向提示**：指出应观察的对象、可用定义或下一步策略，不写出关键计算结果。
- **关键步骤提示**：给出完成当前关键转换所需的条件、式子、图象定位或检查动作；可以给出中间量，但不直接写最终答案。
- **完整解析**：按关键步骤给出从题设到结论的完整自编推理，包含必要的边界、单位或定义域核验，并回到题目所问。

使用任一级提示不阻止提交。作答记录必须分别保留 `最高已用提示级别` 与 `是否独立完成`；“看过完整解析后答对”绝不能记录为独立完成。

### 原子错因与反馈语言

- `M01` 只有一个计数错因。若存在其他合理解释，逐条列为“诊断候选（不计数）”，只用于答案提交后的确认，不增加题数。
- 反馈格式为“你的答案与……不一致，**可能**是……；请确认是否如此”，随后给出对应的复查动作。不能把自动推断写成“你就是因为……错了”。
- 错因必须落在可观察的动作上，如“未先写全集”“把 `{0}` 当作 `∅`”“去分母时漏乘括号内一项”；不用“粗心”“没认真”作为错因。
- 正确答案也应给出简短的核对依据；不以只显示“正确”结束。

## 5. 从矩阵蓝图到成题的展开规则

1. 基础例题、四道基础练习和 `M01` 均继承所在行的三要素蓝图。基础练习恰有四个变体时按书写顺序对应 `B01` 至 `B04`；少于四个时按书写顺序循环；“由……到……”或“逐步”按难度递增排入四题。
2. `M01` 题面沿用主蓝图的数据约束，仅嵌入“计数错因”；其方法固定采用“提交前检查”后的动作。诊断候选不进入题面。
3. `R` 与 `X` 同样继承主蓝图。矩阵格内的变化方向覆盖考查目标，新增条件收紧数据约束，格末动作覆盖预期方法。综合应用节点的 `X01` 必须在题目记录中列出每个连接节点 ID。
4. 可能多解时，题面必须明示蓝图已经要求的象限、符号、区间、整数性或定义域条件。多个并列条件可组成一道分步题，但不得拆成未计数题。
5. 高风险题把提交前检查放在最终提交按钮前；低风险题不为形式而附加检查。基础计算默认不用计算器，只有探索复杂规律时可在题面明确允许。

## 6. 掌握度出口与作答记录

节点状态使用“未学习、学习中、初步掌握、稳定掌握、需要复习”。课程作者须在节点末尾写出下列出口，后续录入必须按同一口径记录。

| 事件 | 写入条件 | 必须记录 | 对节点状态的作用 |
|---|---|---|---|
| 独立基础作答 | 作答前未打开任何提示，答案与该题可接受答案集合一致。 | 题目 ID、正确性、`最高已用提示级别=无`、`独立完成=是`、日期。 | 计入基础掌握证据。 |
| 提示下基础作答 | 打开方向提示、关键步骤提示或完整解析后提交。 | 题目 ID、正确性、最高已用提示级别、`独立完成=否`、日期。 | 记录学习进展，不计作独立基础通过。 |
| 初步掌握 | 在一次完成的基础练习轮次中，`B01`–`B04` 均独立答对；`M01` 已完成并显示相应复查动作。 | 本轮四个 `B` 的作答记录、`M01` 完成记录、获得日期。 | 从“学习中”进入“初步掌握”。 |
| 稳定掌握 | 自初步掌握日起至少间隔 7 天，在一次间隔复习中用四道与 `B01`–`B04` 分别同目标的等价基础变式全部独立答对。复习变式记录其 `source_question_id`，但不新发永久题号。 | 间隔天数、四条来源题 ID、正确性、最高提示级别、独立完成标记、日期。 | 从“初步掌握”进入“稳定掌握”。 |
| 需要复习 | Mya 手动标记，或一次基础练习/间隔复习出现未独立通过的题。 | 触发题目 ID、正确性、提示使用和 Mya 确认的可能错因。 | 不抹除历史证据；推荐回到相应基础动作和按需补给。 |

挑战题的记录独立于上述基础掌握度：只写 `挑战状态=正在挑战` 或 `挑战状态=完成`，以及题目 ID、日期、提示使用和可选反思。挑战答错、未完成或在提示下完成均不得降低“初步掌握”或“稳定掌握”；挑战完成也不得跳过基础与间隔复习的条件。

## 7. 节点交付前检查清单

- 永久节点 ID、学习目标和时长能在第一批矩阵定位；所有新增题 ID 均符合本契约且全局唯一。
- 已按固定顺序写完情境问题、尝试作答、可视化探索说明、概念归纳、例题、四道基础练习、`M01`、矩阵所需的巩固/挑战、三级提示、答案与节点总结。
- 每个题号均有完整题面、可判定答案、三级提示、关键步骤、原子错因或可说明的干扰项理由；高风险题有可执行的提交前检查。
- `M01` 只有一个计数错因；诊断候选不计数、不入题面；所有自动诊断均使用“可能错因”表述。
- 本地巩固只用 `R`，挑战只用 `X`；共享题只用稳定 `SP-Cxx-yy`，且完整内容仅出现在唯一归属节点。
- 掌握度记录能区分独立完成与提示下完成，初步掌握与稳定掌握均满足本文件的明确条件，挑战不影响基础掌握度。
