# 第一批课程内容审阅入口

> 状态：用户已于 2026-09-03 确认

本批交付的是课程规划与覆盖蓝图，不含完整题面、题目解析、教材页面复制内容，也不含页面开发或 `src`、`public` 等应用代码修改。请按以下顺序审阅：

1. [课程范围与知识节点规则](./01-curriculum-scope.md)：确认人教 A 版高一全年范围、上学期五章边界、节点编号、标签和版权约束。
2. [高一全年数学知识图谱](./02-grade-10-knowledge-graph.md)：确认全年章—节—最小学习停靠点的粒度、前置关系和重要度标注。
3. [上学期知识点—例题—练习覆盖清单](./03-semester-1-coverage-matrix.md)：确认五章的题目覆盖蓝图、难度比例、易错辨析、补给与掌握度入口。

## 本批关键决策

- 全年地图覆盖必修第一册与第二册十章；第一批完整覆盖上学期五章，第二册只保留图谱骨架。
- “函数的概念与性质”作为首个完整示范单元；集合内容按学校进度精简同步开放。
- 节点使用永久编号 `M1/M2-Cxx-Sxx-Kxx`，并统一使用基础支撑、核心高频、综合应用三类重要度。
- 覆盖清单以自编内容为目标，按基础、巩固、挑战分层，并明确共享综合题的唯一计数规则。

## 请分别审批

请在审阅后分别确认以下四项：

1. 课程边界：全年十章、上学期五章、集合精简同步范围及函数完整单元定位是否符合预期。
2. 图谱粒度：最小学习停靠点、永久节点编号和直接前置关系是否足够清晰且可执行。
3. 重要度标注：基础支撑、核心高频、综合应用的判定与使用边界是否通过。
4. 题目覆盖蓝图：各节点的例题、练习、易错、补给、挑战和共享题计数安排是否通过。

本批获批只代表第一批课程规划可以进入下一阶段内容制作；不会自动批准第二批交付，也不会自动批准任何代码开发。正式开发仍须遵循设计规格中的分批审批与开发前交付要求。
